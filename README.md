# CloudChat

A basic Global Chat plugin for Velocity proxy server

Support LuckPerms Prefix and Suffix

Support MiniMessage parsing for Prefix/Suffix (player cannot send message with MiniMessage format)

> Note: This plugin is create with assistance from DeepSeek

# Config

There is currently no configuration for the plugin, and I do not intend to add customizable config into this plugin at all.

# Usage

These are some commands that can be used by this plugin:

- `/gc <message>` - Send a message globally
- `/gc $on` - Enable global chat
- `/gc $off` - Disable global chat (cannot see/send global chat)
